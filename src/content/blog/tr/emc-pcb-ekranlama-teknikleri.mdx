Endüstriyel elektronik kartlarda Elektromanyetik Uyumluluk (EMC) standartlarını (CISPR 32 / EN 55032) yakalamak, tasarım aşamasında katman diziliminin (Stackup) ve empedans kontrolünün doğru yapılmasına bağlıdır.

## 1. Karakteristik Empedans ve Geri Dönüş Yolu

Mikroşerit (Microstrip) iletken hatlarda karakteristik empedans $Z_0$ hesabı:

$$Z_0 \approx \frac{87}{\sqrt{\epsilon_r + 1.41}} \ln\left( \frac{5.98 h}{0.8 w + t} \right)$$

Burada:
- $h$: Dielektrik yüksekliği
- $w$: İletken genişliği
- $t$: Bakır kalınlığı
- $\epsilon_r$: Dielektrik sabiti (FR-4 için $\approx 4.3$)

Yüksek frekanslı işaretlerde akım en az dirençli değil, **en az endüktanslı** yolu izler. Bu yol referans düzlemi üzerindeki tam iletken altı geri dönüş yoludur (Return Path).

## 2. Verilog Test-Bench ile Saat Sinyali Gürültü Simülasyonu

Yüksek saat frekanslarında parazitik emisyonları test etmek için yazılan basit Verilog modellemesi:

```verilog
module emi_clock_divider (
    input wire clk_in,
    input wire rst_n,
    output reg clk_out
);

    reg [3:0] counter;

    always @(posedge clk_in or negedge rst_n) begin
        if (!rst_n) begin
            counter <= 4'b0000;
            clk_out <= 1'b0;
        end else begin
            if (counter == 4'd9) begin
                counter <= 4'b0000;
                clk_out <= ~clk_out; // 10'a bölme ile dF düşürme
            end else begin
                counter <= counter + 1'b1;
            end
        end
    end

endmodule
```

## 3. EMC Tasarım Kuralları Listesi

- **Topraklama Dikişi (Via Stitching):** Düzlem geçişlerinde $\lambda/20$ aralıklarla ekranlama viası yerleştirin.
- **20-H Kuralı:** Güç düzlemini toprak düzleminden $20 \times h$ kadar içeride tutarak kenar ışınımını azaltın.
- **Ferrit Boncuk (Ferrite Bead):** Hassas analog kat beslemelerini dijital gürültüden izole etmek için T-Filtre (LC) kullanın.
