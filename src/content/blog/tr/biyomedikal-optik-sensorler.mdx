Biyomedikal optik sensörler, insan dokusundan geçen ışık miktarındaki mikro değişimleri ölçer. Dokudan yansıyan sinyal genellikle ortam gürültüsünün (güneş ışığı, 50Hz/60Hz şebeke armoniği) altındadır.

## 1. Beer-Lambert Yasası ve Dokuda Işık Yutulumu

Işığın doku içerisindeki yutulumu Beer-Lambert yasası ile modellenir:

$$I = I_0 \cdot e^{-\alpha(\lambda) \cdot c \cdot d}$$

Burada:
- $I_0$: Giren ışık şiddeti
- $\alpha(\lambda)$: Hemoglobin yutulum katsayısı
- $c$: Kırmızı kan hücresi konsantrasyonu
- $d$: Doku derinliği

---

## 2. Python ile Faz Kilitli Algılama (Lock-in Amplification)

Ortam ışığı ve 50Hz gürültü altında modüle edilmiş optik sinyali süzmek için kullanılan Python örneği:

```python
import numpy as np

def lock_in_demodulate(signal, ref_in_phase, ref_quadrature, sampling_rate):
    """
    Faz kilitli yükselteç (Lock-in Amplifier) demodülasyon simülasyonu.
    """
    # 1. Çarpma (Demodülasyon)
    mixed_i = signal * ref_in_phase
    mixed_q = signal * ref_quadrature

    # 2. Düşük Geçiren Filtre (Alçak Geçiren Filtreleme)
    fc = 5.0 # Cut-off frequency 5 Hz
    dt = 1.0 / sampling_rate
    alpha = 2 * np.pi * dt * fc / (2 * np.pi * dt * fc + 1)

    filtered_i = np.zeros_like(mixed_i)
    filtered_q = np.zeros_like(mixed_q)

    for k in range(1, len(signal)):
        filtered_i[k] = filtered_i[k-1] + alpha * (mixed_i[k] - filtered_i[k-1])
        filtered_q[k] = filtered_q[k-1] + alpha * (mixed_q[k] - filtered_q[k-1])

    magnitude = 2 * np.sqrt(filtered_i**2 + filtered_q**2)
    return magnitude
```

## 3. Öne Çıkan Notlar

- Senkron demodülasyon ile gürültü tabanı (Noise Floor) 40 dB seviyesine kadar düşürülebilir.
- LED sürüş devresinde düşük parazitik kapasiteli MOSFET anahtarlama tercih edilmelidir.
