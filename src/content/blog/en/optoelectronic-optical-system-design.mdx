In optoelectronic system design, focusing light onto the photodiode surface with minimal loss and maximum Signal-to-Noise Ratio (SNR) is the most critical stage.

## 1. Optical Focusing & Quantum Efficiency

The relationship between optical power $P_{opt}$ incident on a photodiode and the generated photocurrent $I_{ph}$ is expressed through quantum efficiency ($\eta$) and wavelength ($\lambda$):

$$I_{ph} = \frac{\eta \cdot q \cdot \lambda}{h \cdot c} \cdot P_{opt}$$

Where:
- $\eta$: Photodiode Quantum Efficiency
- $q$: Electron charge ($1.602 \times 10^{-19} \text{ C}$)
- $h$: Planck's constant ($6.626 \times 10^{-34} \text{ J}\cdot\text{s}$)
- $c$: Speed of light ($3 \times 10^8 \text{ m/s}$)

### Rayleigh Diffraction Limit
The resolving power of the lens system is governed by the Rayleigh Criterion:

$$\theta = 1.22 \frac{\lambda}{D}$$

## 2. C++ Simulation Model

```cpp
#include <iostream>
#include <cmath>

class OptoelectronicSensor {
private:
    const double h = 6.626e-34; // Planck
    const double c = 3.0e8;     // Speed of light
    const double q = 1.602e-19; // Electron charge

public:
    double calculatePhotoCurrent(double powerWatts, double lambdaMeters, double quantumEfficiency) {
        return (quantumEfficiency * q * lambdaMeters / (h * c)) * powerWatts;
    }

    double calculateSpotDiameter(double lambdaMeters, double fNumber) {
        return 2.44 * lambdaMeters * fNumber;
    }
};

int main() {
    OptoelectronicSensor sensor;
    double lambda = 850e-9; // 850 nm IR Laser
    double fNum = 2.8;
    double power = 1e-6;    // 1 uW Optical Power
    double qe = 0.85;       // 85% QE

    double current = sensor.calculatePhotoCurrent(power, lambda, qe);
    double spotSize = sensor.calculateSpotDiameter(lambda, fNum);

    std::cout << "Photocurrent: " << current * 1e6 << " uA" << std::endl;
    std::cout << "Diffraction Spot Size: " << spotSize * 1e6 << " um" << std::endl;
    return 0;
}
```
