Achieving Electromagnetic Compatibility (EMC) compliance (CISPR 32 / EN 55032) in industrial electronics relies on proper layer stackup and impedance matching during early design stages.

## 1. Characteristic Impedance & Return Path

For microstrip traces, characteristic impedance $Z_0$ is approximated by:

$$Z_0 \approx \frac{87}{\sqrt{\epsilon_r + 1.41}} \ln\left( \frac{5.98 h}{0.8 w + t} \right)$$

High-frequency return currents follow the path of **least inductance**, directly beneath the signal trace on the reference plane.

## 2. Verilog Clock Divider EMI Simulation

```verilog
module emi_clock_divider (
    input wire clk_in,
    input wire rst_n,
    output reg clk_out
);

    reg [3:0] counter;

    always @(posedge clk_in or negedge rst_n) begin
        if (!rst_n) begin
            counter <= 4'b0000;
            clk_out <= 1'b0;
        end else begin
            if (counter == 4'd9) begin
                counter <= 4'b0000;
                clk_out <= ~clk_out;
            end else begin
                counter <= counter + 1'b1;
            end
        end
    end

endmodule
```
